# GitHub submission

Suggested repository name: maze-solver-ai

Suggested description: Interactive maze solver comparing BFS and A* with reproducible benchmark results.

The folder containing main.py is the repository root. The code, README, results,
images, and docs belong together. A reader should see main.py immediately when
opening the repository, and the README should display on its home page.

If creating the repository on GitHub, choose the visibility that provides your
instructor access. Public repositories can be viewed from their link without
an invitation. Private repositories require access for the reviewer.

For a browser upload, create the repository and choose Add file, then Upload
files. Upload the contents of the extracted MazeSolver folder, including its
results, images, and docs folders. The included README already describes the
project. Keep the individual source files available in the repository so the
instructor can inspect and run them.

A suggested commit message is: Add maze solver and recorded benchmark results

After publishing, open the repository link and check that main.py, search.py,
mazes.py, benchmark.py, test_search.py, README.md, and results/benchmark.csv are
present. The README's screenshot images should load. Run the downloaded code
from a fresh folder with python main.py when checking reproducibility.

Use the repository's actual URL for the code submission. A GitHub Pages website
is not needed to submit this desktop Python project.
